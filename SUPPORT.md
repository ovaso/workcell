# Support

This project is maintained on a best-effort basis and does not provide a guaranteed response time or commercial support agreement.

Use GitHub Issues for:

- reproducible defects;
- specification ambiguities;
- portability problems;
- documentation gaps;
- focused feature proposals.

Before opening an issue, search existing issues, use the appropriate issue form, remove credentials and private project information, and include the product version, host platform, command, expected result, actual result, and minimal reproduction.

Do not use public issues for vulnerabilities or sensitive operational details. Follow `SECURITY.md` instead.

Questions about a private project, business policy, or unsupported local modification may be closed when they cannot be answered without confidential context. General usage questions should include only sanitized, reusable information.
